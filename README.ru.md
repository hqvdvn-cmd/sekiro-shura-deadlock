# Волк / Шура для Ямато — бета

**Мод не финальный и будет дорабатываться.**

Волк в облике Шуры заменяет Ямато. В комплекте Кусабимару, красный Клинок бессмертных, чёрный меч за спиной, эффекты атак и навыков, отбив в духе Sekiro. В ульте — чёрные волосы и красный светящийся глаз. На выборе героя имя «Шура» и подписи Shadows · Die · Twice.

[Скачать бету](https://github.com/hqvdvn-cmd/sekiro-shura-deadlock/releases/tag/v29-beta)

## Установка

Закрой Deadlock и менеджер, отключи другие замены Ямато. Импортируй `sekiro-shura-v29-beta-standalone-r2.zip` и включи три компонента: модель/UI/озвучка, эффекты Ямато и привязка ульты.

С **Dota 2 → Deadlock** оставь модель и эффекты, отключи отдельный компонент привязки ульты Шуры, затем импортируй и включи `sekiro-shura-v29-beta-dota-patch-r2.zip`. Все пять компонентов D2D остаются включёнными. Одновременно нужна только одна привязка ульты Шуры.

Вручную: скопируй три VPK в `game/citadel/addons`. В `gameinfo.gi` → `FileSystem` → `SearchPaths` поставь `Game citadel/addons` выше `Game citadel`. Сохрани остальные пути и явные `Mod`/`Write` для `citadel` и `core`. С D2D замени только принадлежащий этому моду pak16 и manifest на версии из совместимого patch. Чужие файлы с тем же именем не перезаписывай.

Для удаления отключи мод и его patch в менеджере. При ручной установке удаляй только файлы, совпадающие с manifest скачанного архива. Менеджеры могут менять номера VPK.

## Что ещё требует работы

- Хват, поза выбора и вкладывание меча в ножны могут требовать правок.
- В начале парирования может появляться короткая синяя вспышка. Общие эффекты движения и парирования сохраняют родные цвета.
- Японская синтетическая озвучка пока черновая, некоторые реплики рваные. Улучшение голоса отложено.
- Имя и подписи заменены для русского и английского; другие моды локализации/Ямато могут конфликтовать.

Бой, перезарядку и ульту ранее проверял владелец в общем комплекте модов. Новые изменения кисти и меча V29 проверены по скомпилированным ресурсам и установлены; свежая игровая проверка и отдельный матч без других модов ещё нужны.

Скриншоты в английском README сняты на предыдущей рабочей версии. Для проверки после патча распакуй основной ZIP и выполни `python verify.py --game-dir "ПУТЬ_STEAM/Deadlock/game/citadel"` с Python 3.10+. Скрипт только читает файлы, игру не запускает. Он проверяет выбранные ресурсы, а не всю совместимость.

В отчёте о баге укажи действие/позу, сборку игры и другие моды, приложи скриншот или ролик.
